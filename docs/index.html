🍎 macOS Dev Setup

One-command dev environment setup on macOS: Homebrew, CLI tools, Tabby, Docker (Colima), Node.js 24, and pnpm.

⚡ One-command install

Paste this into Terminal (replace UncannyCorp with your GitHub username or org):

curl -fsSL https://raw.githubusercontent.com/UncannyCorp/macos-dev-setup/main/install.sh | bash

Requires macOS and zsh (default shell). The script may prompt for Xcode Command Line Tools; complete that, then re-run if needed.

📦 What gets installed

  • CLI: Xcode Command Line Tools, Homebrew, git, wget, curl, jq, yq, tree, ripgrep, fd, fzf, htop, btop, tmux, watch, unzip, p7zip, gnupg, openssl
  • GUI (casks): GitHub Desktop, Tabby terminal
  • Containers: Colima, Docker CLI, docker-compose (no Docker Desktop)
  • Node: NVM, Node.js 24, pnpm (via Corepack)
